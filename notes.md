# Git and GitHub Notes

## What is Version Control?
Version control is a system that tracks changes made to files over time.

## What is Git?
Git is a version control tool that helps developers manage and track code changes.

## What is GitHub?
GitHub is an online platform used to store Git repositories and collaborate with others.

## Basic Git Commands

### Check repository status
```bash
git status
```

### Add files
```bash
git add .
```

### Create a commit
```bash
git commit -m "message"
```

### Push changes to GitHub
```bash
git push origin main
```

## Why Use GitHub?
- Keeps project history
- Helps collaboration
- Allows backups online
- Makes teamwork easier


## Important Workflow Steps
1. Create files
2. Add changes
3. Commit changes
4. Push to GitHub
5. Create branches
6. Open pull requests
7. Merge updates
